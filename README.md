# TheGhostTerminal

IT support and network security, based in Dubai. I keep Linux servers and small
networks running, and I break them in labs to learn how they fail.

**What I work on**

- Linux administration: Nextcloud on Docker Compose behind Caddy, with a private certificate authority and automated renewals
- Networking: DNS (dnsmasq, split-horizon), NAT and forwarding, a ZeroTier overlay used as an exit node
- Automation: Python and Bash, systemd timers that check the boring things and repair them
- Detection: Sigma rules and hunting queries written from techniques I have run in labs

**Learning in the open**

- Hack The Box Starting Point: 8 machines, Meow through Responder
- HTB Academy: Junior Cybersecurity Analyst path, currently on Windows Fundamentals

**Repos worth a look**

- [htb-writeups](https://github.com/the-ghostterminal/htb-writeups): reproducible writeups for retired Hack The Box machines, commands re-run before publishing
- [detection-rules](https://github.com/the-ghostterminal/detection-rules): Sigma rules and hunting queries built from the techniques those boxes used
- [wifi_extractor](https://github.com/the-ghostterminal/wifi_extractor): PowerShell that exports saved Wi-Fi profiles and their keys on Windows, for machines you own
- [SmartSpendAI](https://github.com/the-ghostterminal/SmartSpendAI): Next.js and Gemini finance app with receipt OCR and expense tracking
